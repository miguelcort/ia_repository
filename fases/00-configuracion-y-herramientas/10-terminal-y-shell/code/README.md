# Terminal y shell

Comandos utiles para el flujo de IA:

```bash
cd code
chmod +x main.sh
./main.sh info
./main.sh env-python
./main.sh count-words README.md
./main.sh random-id
./main.sh fecha
```

Ejecuta los tests:

```bash
bash code/tests/test_main.sh
```

O desde la raíz del repo:

```bash
python3 scripts/probar_lecciones.py --quiet
```
