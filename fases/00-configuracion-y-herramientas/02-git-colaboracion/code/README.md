# Git y colaboración

Ejecuta el script principal:

```bash
chmod +x code/main.sh
./code/main.sh check       # valida repo + identidad
./code/main.sh sample      # valida un mensaje de commit
./code/main.sh report      # estado del repo
```

Ejecuta los tests:

```bash
bash code/tests/test_main.sh
```

O desde la raíz del repo:

```bash
python3 scripts/probar_lecciones.py --quiet
```
