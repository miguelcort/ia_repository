## Prerrequisitos

- Fase 0 (setup).
- Fase 1 (matemáticas) — deseable, no bloqueante.

## Material de referencia

Las lecciones de esta fase cubren regresión, clasificación, clustering,
ingeniería de *features*, evaluación y *ensembles*. Reemplazan el
material introductorio y de modelos clásicos que antes se veía al
comienzo del diplomado.

## Objetivos de la fase

- Implementar regresión, clasificación y clustering desde cero.
- Diagnosticar sobre/subajuste con curvas de aprendizaje.
- Construir pipelines reproducibles con tracking de experimentos.
- Saber cuándo un modelo clásico supera a una red neuronal profunda.
