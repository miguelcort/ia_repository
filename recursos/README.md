# 📚 Recursos

> Material complementario al currículo: cheatsheets, presentaciones y
> scripts auxiliares.

## Organización

```text
recursos/
├── cheatsheets/         # Hojas resumen por tecnología
├── presentaciones/      # Diapositivas de clase
└── scripts/             # Utilidades comunes
```

## Política

- Cada recurso se enlaza desde la lección correspondiente.
- Lenguaje de los recursos: español, salvo que la fuente original esté
  en inglés y no exista traducción.
- Cualquier recurso de terceros cita la fuente y respeta su licencia.
