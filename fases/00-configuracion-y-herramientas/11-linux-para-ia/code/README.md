# Linux para IA

Diagnostico rapido del sistema:

```bash
cd code
chmod +x main.sh
./main.sh who
./main.sh resources
./main.sh os-info
./main.sh top-processes
./main.sh listening
```

Ejecuta los tests:

```bash
bash code/tests/test_main.sh
```

O desde la raíz del repo:

```bash
python3 scripts/probar_lecciones.py --quiet
```
